### 5.2 解压规则

目标目录：

```
data/datasets/raw_extracted/<dataset>/
```

算法：

1. 用 `zipfile.ZipFile` 逐个读取。
2. 如果条目本身是 zip（`PK\x03\x04`），递归解压到同级目录。
3. 文件名编码：先按 UTF-8；失败则 `cp437 -> gbk` 再试 `cp437 -> utf-8`。
4. 保留原始目录结构，不要扁平化。
5. 解压后统计：图片数、标注文件数、顶层目录、总大小。
6. 写入 `data/eval/raw_inventory.csv`（`inspect_raw_datasets.py` 已有基础版，可扩展）。

### 5.4 标注格式识别

按优先级判断：

1. **YOLO**：存在 `data.yaml` / `dataset.yaml`，且有 `images/` 与 `labels/`，标签是 `.txt`（`class cx cy w h`）。
2. **COCO**：存在 `*.json`，含 `images`、`annotations`、`categories`。
3. **分类**：目录名就是类别（如 `normal/`、`defect/`、`good/`、`bad/`）。
4. **只有图片无标签**：作为参考/负样本池，不进入有监督训练。

保留原始标签文件；不要改写标签，除非明确需要统一格式。

### 5.5 质量门禁

逐张检查：

- 能打开（PIL），不是 0 字节
- 短边 ≥ 512（低于 512 的只留作参考，不进训练）
- 不是纯示意图/拼图/带大面积水印
- 不是重复图（sha1）
- 与目标设备形态接近（人工抽样 10 张/数据集）

不合格的放进 `rejected/`，不要删除。

### 5.6 去重与切分

- 全库按 `sha1` 去重；同一张图跨数据集出现时保留一份，标签做多标签。
- 切分按 `sha1[:8] % 10`：
  - `< 7` → train
  - `< 9` → val
  - 否则 test
- **同一 sha1 必须落在同一 split**，避免泄漏。

### 8.2 Prompt 原则

**一次只问一个子项**，不要把 45 项塞进一个 prompt。

模板：

```text
你是化工设备巡检视觉判定器。只判断一个检查项。

检查项：{sub_code} {sub_name}
判据：{criteria}
上下文：{point/equipment metadata，若没有则写“无”}

纪律：
- 看不清/被遮挡/画面中没有该对象 → present=false, undecidable=true
- confidence 取 0~1 的真实把握，禁止照抄示例
- bbox 用 0~1000 相对坐标；无法给出写 null
- 只输出严格 JSON，不要 markdown

输出：
{"present": false, "confidence": 0.0, "evidence": "", "bbox": null, "undecidable": false, "reason": ""}
```

### 8.3 调用

- 模型：`qwen3-vl-plus`（现有 `MaasClient`）
- `json_mode=True`
- 一张图一次调用
- 并发 4
- 记录：latency、prompt/completion tokens、原始响应、解析结果

### 8.4 指标

| 指标 | 算法 |
|---|---|
| 召回 | `present=true` / 正样本总数 |
| 无效 JSON 率 | 解析失败 / 总调用 |
| 不可判定率 | `undecidable=true` / 总调用 |
| 平均时延 | P50 / P90 |
| 证据质量 | 人工抽 10 张看 bbox/理由是否对 |

**没有负样本，不要报误报率/精确率**；只能报“正样本召回 + 无效/不可判定”。

### 8.5 成本保护

- 4 组共约 **67 次调用**，可直接跑
- 超过 100 次先问用户
- 失败重试最多 1 次，避免重复烧 token

## 11. 常见问题

| 问题 | 处理 |
|---|---|
| Kaggle 下载 404/401 | 必须登录；让用户手动下载或提供 `~/.kaggle/kaggle.json` |
| zip 里还有 zip | 递归解压；不要假设只有一层 |
| 文件名中文乱码 | `cp437 -> gbk`，失败再 `cp437 -> utf-8` |
| `images=0` | zip 放错目录，或只放了 `.DS_Store` |
| 图片打不开 | 移入 `rejected/`，记录原因 |
| 重复图 | sha1 去重；跨数据集重复保留一份、做多标签 |
| 标签类别与 45 项不一致 | 先列 `classes.txt`，人工映射；不要硬套 |
| Excel 保存后 CSV 列错位 | 用 Numbers/Excel 的“CSV UTF-8”重新导出 |
| 付费调用超预算 | 先停，报预计张数/成本，等用户确认 |
| 结果太好/太差 | 先查是否有重复图泄漏、提示词是否泄漏答案、样本是否过易 |
