# 网上数据源与许可证（45 项检测补充数据）

> 目的：为 45 项检测补“负样本/缺失项参考图”。
> 底线：**许可证不清的图不进训练集，也不进交付包**；网图只做参考/预训练/冒烟测试，不替代现场同分布负样本。

## 一、许可证分级

| 级别 | 许可证 | 处理方式 |
|---|---|---|
| 绿 | CC0 / Public domain / CC BY / MIT / Apache-2.0 | 可下载；记录作者与许可证 |
| 黄 | CC BY-SA | 可下载，但**隔离到 `share_alike/`**，仅内部参考，交付前做法务确认 |
| 黄 | 许可证为 `other` / `unknown` | 不下载，先联系作者或读原始条款 |
| 红 | 搜索引擎图片、无 LICENSE 仓库、付费数据集预览图 | 不使用 |

## 三、Wikimedia Commons（负样本/参考图）

脚本：`scripts/fetch_web_samples.py`

- 只收 JPG；默认跳过 PNG（多为示意图）。
- 标题必须命中检索词；跳过 logo/diagram/档案图/模型/玩具等。
- 使用 1280px 缩略图，避免下载几十 MB 原图。
- CC BY-SA 隔离到 `data/datasets/web/share_alike/`。
- 每张图记录到 `data/datasets/web/LICENSES.csv`。

运行：

```bash
.venv/bin/python scripts/fetch_web_samples.py --per-query 3 --max-queries 1 --include-sharealike
# 只跑某几项
.venv/bin/python scripts/fetch_web_samples.py --items CI-06,CI-17 --per-query 5
```

## 五、域匹配警告

- Commons/Kaggle 的图多为欧美设备、不同光照与拍摄距离；与本项目 750×1000 的现场近景差异大。
- 网图负样本只能作为**参考/预训练**；真正的误报率必须用现场同点位、同相机的正常图来测。
- 每项至少补 5 张现场负样本，才能谈精确率。
