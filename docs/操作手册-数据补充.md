## 一、准备工作

### 1. 确认目录存在

打开「终端」，执行：

```bash
cd '/Users/nanyu/Documents/AI/AI项目/化工巡检'
ls data/datasets/web/raw
```

应该看到：

```
README.md  bolts-and-washers  hard-hat  npu-bolt  person-forklift  pressure-gauge
```

如果没有，先执行：

```bash
mkdir -p data/datasets/web/raw/{npu-bolt,pressure-gauge,bolts-and-washers,hard-hat,person-forklift}
```

### 2. 磁盘空间

5 个包合计约 **2.1 GB**，解压后约 4~6 GB。确认磁盘剩余 ≥ 10 GB。

### 3. Kaggle 账号

没有账号先注册：https://www.kaggle.com/  
注册后登录，部分数据集会要求 **手机验证**，按页面提示做即可。

## 二、下载 Kaggle 包（逐个操作）

> 每个包的操作都一样：打开页面 → 点 Download → 把 zip 放进指定目录。
> **不需要解压，不需要改文件名。**

### 包 1：NPU-BOLT（最重要）

- 页面：https://www.kaggle.com/datasets/yartinz/npu-bolt
- 大小：约 525 MB
- 放置目录：

```
data/datasets/web/raw/npu-bolt/
```

操作：

1. 浏览器打开上面的链接
2. 登录 Kaggle
3. 页面右上角点 **Download**
4. 下载完成后，把 zip 拖进 `raw/npu-bolt/`
5. 如果下载文件名是 `archive.zip`，可以改名为 `npu-bolt.zip`（可选）

### 包 2：压力表真实图

- 页面：https://www.kaggle.com/datasets/asamasach/industrial-pressure-gauge-images
- 大小：约 26 MB
- 放置目录：

```
data/datasets/web/raw/pressure-gauge/
```

### 包 3：螺栓/垫圈

- 页面：https://www.kaggle.com/datasets/ahmedmohamedab/bolts-and-washers
- 大小：约 67 MB
- 放置目录：

```
data/datasets/web/raw/bolts-and-washers/
```

### 包 4：叉车+人员

- 页面：https://www.kaggle.com/datasets/hakantaskiner/personforklift-dataset
- 大小：约 189 MB
- 放置目录：

```
data/datasets/web/raw/person-forklift/
```

### 包 5：安全帽（可选）

- 页面：https://www.kaggle.com/datasets/andrewmvd/hard-hat-detection
- 大小：约 1.3 GB
- 放置目录：

```
data/datasets/web/raw/hard-hat/
```

> 安全帽可以**先不下**：`raw/hf-hard-hat/` 里已经有 997 张 CC0 版本（虽然带水印，但能先用）。
> 如果下，也不冲突，我会合并去重。

### 下载顺序建议

1. NPU-BOLT（525 MB）
2. 压力表（26 MB）
3. 螺栓/垫圈（67 MB）
4. 叉车（189 MB）
5. 安全帽（1.3 GB，最后）

## 四、人工审核 Commons 候选图

这一步是“把网图里明显不对的删掉”。**不做也可以**，我可以按自己的判断处理，但你自己过一遍更稳。

### 1. 打开联系表

在终端执行：

```bash
cd '/Users/nanyu/Documents/AI/AI项目/化工巡检'
open data/eval/web_contact_sheet_1.jpg
open data/eval/web_contact_sheet_2.jpg
```

- 第 1 张 40 图，第 2 张 34 图
- 每张图下面有 `review_id`，例如 `CI-06-001`
- `review_id` 和 `data/eval/web_review.csv` 的 `review_id` 列一一对应

### 2. 打开审核表

用 **Numbers** 或 **Excel** 打开：

```
data/eval/web_review.csv
```

找到最后两列：

| 列名 | 填什么 |
|---|---|
| `人工保留(1/0)` | **1 = 留下，0 = 删掉，空 = 还没看** |
| `人工备注` | 可选，写原因 |

示例：

| review_id | 人工保留(1/0) | 人工备注 |
|---|---|---|
| CI-06-001 | 1 | 螺栓清晰，保留 |
| CI-13-001 | 0 | 这是上海外滩，不是围堰 |
| CI-21-002 | 0 | 这是烟灰缸，不是视镜 |

### 3. 保存

- **Numbers**：文件 → 导出到 → CSV，编码选 **UTF-8**
- **Excel**：文件 → 另存为 → 格式选 **CSV UTF-8（逗号分隔）**

> 不要保存成 `.xlsx`，否则脚本读不了。

### 4. 应用审核结果

在终端执行：

```bash
cd '/Users/nanyu/Documents/AI/AI项目/化工巡检'
.venv/bin/python scripts/apply_web_review.py
.venv/bin/python scripts/fetch_web_samples.py --coverage-only
```

`apply_web_review.py` 会：

- 把 `1` 的行标记为保留
- 把 `0` 的行移到 `data/datasets/web/rejected/`
- 更新 `LICENSES.csv` 的 `status`
- 重新生成覆盖表

### 5. 不想逐行填怎么办

直接把要删的 `review_id` 发我，例如：

## 六、常见问题

### Q1：点 Download 没反应 / 要求登录

先登录 Kaggle；部分数据集要手机验证。验证后刷新页面再点。

### Q2：下载下来是文件夹，不是 zip

浏览器一般给 zip。如果是文件夹，直接整个文件夹拖进对应目录也可以，告诉我即可。

### Q3：zip 里面还有 zip

正常，Kaggle 有些包是嵌套的。不用你解，我来处理。

### Q4：文件名重复，变成 `archive (1).zip`

可以改名为：

```
npu-bolt.zip
pressure-gauge.zip
bolts-and-washers.zip
person-forklift.zip
hard-hat.zip
```

不改也能用，目录名已经区分。

### Q5：Excel 打开 CSV 中文乱码

用 **CSV UTF-8** 保存；如果已经乱码，重新用 Numbers 打开原文件再导出 UTF-8 CSV。

### Q6：Numbers 保存后列错位

确认导出的是 **CSV**，分隔符是逗号，编码 UTF-8。不要加标题行、不要合并单元格。

### Q7：脚本报“找不到 web_review.csv”

确认你在项目根目录执行：

```bash
cd '/Users/nanyu/Documents/AI/AI项目/化工巡检'
```

### Q8：脚本报权限错误

确认 `data/` 目录可写；不要用 `sudo` 跑项目脚本。

### Q9：下载中断/zip 损坏

重新下载；对比页面显示的大小。zip 打不开就删掉重下。

### Q10：Kaggle 要 API Token，不想用浏览器

也可以：Kaggle → 头像 → Settings → API → Create New API Token，把 `kaggle.json` 放到 `~/.kaggle/kaggle.json`，告诉我路径，我来下。**不要把 key 贴在聊天里。**
