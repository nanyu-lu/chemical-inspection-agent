# 隐患识别 Agent · MVP 开发计划

> 场景：化工巡检 —— 甲类危化品仓库 库位合规校验
> 形态：框架本地运行（FastAPI + SQLite + 本地文件），模型走千炼（OpenAI 兼容）
> 目标：一期「完成隐患识别 agent，提交化工专家审查」

## 一、MVP 范围

### 做（P0）

| # | 功能 |
|---|---|
| 1 | 图片 / 短视频上传，按点位（`point_id`）归集为巡检任务 |
| 2 | 视频抽帧（ffmpeg，默认 1 帧/2s，可配） |
| 3 | 千炼视觉判定：类别 / 置信度 / 理由 / 证据 bbox |
| 4 | 规则表裁决：阈值三分支 + 等级映射 + 24h 去重 |
| 5 | 隐患单草稿（对齐台账字段） |
| 6 | 人工确认 / 驳回（驳回必须选原因 → 数据回流） |
| 7 | 看板：按类别 / 点位 / 时间统计 |
| 8 | CSV 导出 |
| 9 | 调用记账（token / 时延 / 成本） |
| 10 | 超时 / 断网降级（转人工，不崩不丢） |
| 11 | Mock 模式（无 Key 也能演示与开发） |

### 不做

YOLO 训练、向量库、Docker/K8s/Redis/Celery、多用户与权限、机器人 ROS2/MQTT 补传、自动派工、模型微调、实时视频流（RTSP）。

## 三、D1 已完成的工作与实测结论

**已落地**

- Python 3.11（uv 托管）+ `uv sync --dev` 一条命令装齐依赖
- 契约：`InspectionFrame` / `HazardEvent` / `ReviewAction` / `VLJudgeOutput` / `MeterReading`，含 UUIDv7 单调 id、bbox 坐标系、驳回必填原因、模型多吐字段即拒收
- 千炼适配层 `MaasClient`：base64 内联、JSON 模式、429/5xx 退避重试、失败抛 `MaasError` 供上层降级
- 探针脚本 + 自动生成报告

**实测结论（合成图，仅验证机制）**

| 项 | 结果 |
|---|---|
| 鉴权 | ✅ 183 个模型，视觉相关 17 个 |
| base64 内联图片 | ✅ 支持 |
| `response_format=json_object` | ✅ 支持（视觉与文本均可用） |
| 视觉时延 / token | 4.1~5.6 s；prompt ≈ 990 tokens，completion ≈ 220 |
| OCR 读表 | ✅ 814~929 ms，准确读出 `0.85 MPa` |

**探针暴露的 3 个缺陷（已修）**

| 编号 | 问题 | 修正 |
|---|---|---|
| KI-01 | 提示词写 `"confidence":0.0`，模型**照抄**，全部返回 0.0 | 示例改 0.82 + 显式「禁止照抄示例」 |
| KI-02 | bbox 是 **0~1000 相对坐标**，按像素裁剪会错位（实测 y2=915 > 图高 720） | `Detection.bbox_space` + `to_pixel_bbox()` 换算裁剪 + 单测 |
| KI-03 | 置信度过高（正例 1.0 / 负例 0.0），不能当唯一判据 | 保留阈值三分支，事件默认 `need_manual_review=true` |

## 五、冻结的三条硬约定

1. **契约冻结**：`contracts/models.py` 只允许向后兼容地新增可选字段，`schema_version` 同步递增。
2. **等级与条款不由模型决定**：`level` / `sop_ref` 只来自 `config/*.yaml`。
3. **无证据不入库**：`verdict.evidence_crop_uri` 为空的事件只能转人工，不得进看板。

## 八、D4/D5 实现说明（2026-11-06）

### 分层

```
api/app.py        只做「收件 → 落盘 → 入队 → 查询」，不碰模型
worker.py         DB 任务表轮询（并发可配，启动时重置卡死的 running）
pipeline.py       纯函数 judge_frame()：预处理→VL→契约校验→规则裁决→证据裁剪
rules.py          阈值/等级/条款/去重，全部来自 hazard_rules.yaml
service.py        持久化、去重、任务进度、统计、导出
db.py             tasks/frames/events/reviews/llm_usage（append-only 事件）
```

### 五个关键实现决策

| 决策 | 原因 |
|---|---|
| 图片 sha256 去重（同任务内） | 重传同一张不重复烧 token |
| 事件 evidence 永不为空（裁剪失败退化为整图） | 「无证据不入库」硬规则 |
| `missing_sop_policy: mark_review` | 条款未到时不静默丢弃真实隐患，只强制复核并标注 |
| SQLite 统一存 UTC naive 时间 | SQLite DATETIME 不支持时区，避免比较报错 |
| 契约里 `bbox_space` 显式落库 | 证据裁剪错位是探针实测过的坑 |

### 实测（真实图片 + 真实千炼 API）

| 项 | 结果 |
|---|---|
| 3 张图（出口堵塞/未戴安全帽/器材遮挡） | 3/3 正确出事件，HZ-06 / HZ-01 / HZ-04 |
| 证据裁剪 | 3 张均生成，`/files/...` 返回 HTTP 200 |
| 复核 | 驳回成功 200 → 重复 409 → 缺原因 422 |
| 冒烟 | 11/11 通过（`scripts/smoke_api.py`） |
| 性能 | 并发 3 时平均 13.9s/张、3714/1298 tokens |
