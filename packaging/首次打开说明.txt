首次打开说明
========================================

【Windows】安装后第一次运行
1. 双击桌面上的「化工巡检」。
2. 如果出现蓝色的「Windows 已保护你的电脑」窗口：
   点击「更多信息」→「仍要运行」。
   （因为本程序没有购买代码签名证书，属于正常提示，只需这一次。）
3. 如果杀毒软件误报：选择「允许」/「信任」，或先把安装目录加入白名单。

【macOS】第一次打开
1. 双击 dmg，把「化工巡检」拖进「应用程序」。
2. 第一次打开如果提示「无法验证开发者」：
   在「应用程序」里右键点「化工巡检」→ 选择「打开」→ 再点「打开」。
   （同样只需一次。）
3. 如果提示“已损坏，无法打开”，在终端执行：
   xattr -dr com.apple.quarantine /Applications/化工巡检.app

【首次运行会要求填写 API Key】
- 粘贴千炼 API Key 后回车，程序会记住（存在你的用户目录，不会外传）。
- 直接留空 = Mock 模式：界面和流程都能走完，但识别结果是示例数据，
  用于演示"系统怎么用"，不代表真实识别效果。

【使用】
- 启动后会弹出一个小窗口，显示「已就绪」并自动打开浏览器。
- 请在小窗口里点「停止并退出」来关闭服务；只关浏览器标签页服务仍在运行。
- 数据位置：
    Windows: %APPDATA%\ChemInspect
    macOS  : ~/Library/Application Support/ChemInspect
- 日志：上述目录下的 logs/api.log（启动失败时先看它）。

【已知限制】
- 不支持视频（需要 ffmpeg）；请上传图片。
- 判定依据条款为草稿，界面会标注「判据待专家确认」。
- 单机演示版没有登录功能，请勿直接暴露到生产网络。
